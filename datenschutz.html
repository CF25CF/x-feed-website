2. Überblick

Wir nehmen den Schutz deiner Daten ernst. X-Feed sammelt nur das absolute Minimum an Daten, das für den Betrieb der App notwendig ist. Wir verwenden kein Tracking, keine Werbung und keine Drittanbieter-Analyse-Tools.

Keine personenbezogenen Daten Kein Tracking HTTPS-verschlüsselt Keine Werbe-IDs

3. Welche Daten werden erhoben?

3.1 Geräte-Kennung (UUID)

Beim ersten Start der App wird auf deinem Gerät eine zufällige Kennung (UUID) erzeugt. Diese ist nicht mit deiner Person, deinem Apple/Google-Konto oder anderen personenbezogenen Daten verknüpft. Die UUID dient ausschließlich dazu, deine App-Installation für Premium-Abonnements und Promo-Codes zu identifizieren.

3.2 App-Aktivität

Bei jedem App-Start wird die UUID zusammen mit einem Zeitstempel an unseren Server gesendet (Heartbeat). Daraus erstellen wir anonyme Statistiken über aktive Nutzer. Es werden keine inhaltlichen Aktionen (z.B. welche News du liest) erhoben.

3.3 Käufe und Abonnements

Beim Abschluss eines Premium-Abos oder beim Wiederherstellen eines Kaufs werden folgende Daten gespeichert:

  • Apple/Google Transaction ID (eindeutige Käufer-Kennung)
  • Status des Abonnements (aktiv, abgelaufen, gekündigt)
  • Ablaufdatum
  • Verknüpfung mit der UUID

Diese Daten werden direkt von Apple bzw. Google über offizielle Schnittstellen (Server Notifications) an unseren Server gemeldet.

3.4 Promo-Codes

Wenn du einen Promo-Code einlöst, wird der eingegebene Code zusammen mit deiner UUID an den Server gesendet, um zu prüfen, ob der Code gültig ist und Premium freizuschalten.

3.5 Push-Benachrichtigungen (optional)

Wenn du Push-Benachrichtigungen aktivierst, erhältst du tägliche Hinweise auf neue Top-News. Die Benachrichtigungen werden direkt auf deinem Gerät geplant (lokale Benachrichtigungen) – wir senden keine Push-Tokens an unseren Server.

4. Welche Daten werden NICHT erhoben?

  • Name, E-Mail oder Telefonnummer
  • Standortdaten
  • Kontakte, Fotos oder andere Geräte-Inhalte
  • Werbe-IDs (IDFA, AAID)
  • IP-Adressen (werden nicht dauerhaft gespeichert)
  • Verhaltens- oder Tracking-Daten
  • Daten für personalisierte Werbung

5. Datenübertragung und Speicherung

Alle Datenübertragungen zwischen App und Server erfolgen verschlüsselt über HTTPS/TLS. Die Server stehen in Deutschland.

Die Daten werden so lange gespeichert, wie es für den Betrieb der App notwendig ist (z.B. solange dein Premium-Abo aktiv ist). Auf Anfrage löschen wir deine UUID und alle damit verknüpften Daten.

6. Drittanbieter

6.1 Apple / Google (In-App-Käufe)

Premium-Abonnements werden über Apple StoreKit bzw. Google Play Billing abgewickelt. Es gelten die Datenschutzbestimmungen von Apple bzw. Google.

6.2 Tagesschau (News-Quelle)

Die Inhalte der News stammen vom öffentlich-rechtlichen RSS-Feed der Tagesschau. Die App selbst kontaktiert die Tagesschau-Server nicht direkt. Die Inhalte werden auf unserem Server abgerufen und über unsere API ausgeliefert.

6.3 KI-Verarbeitung

Zur Erstellung von Zusammenfassungen, Titelanpassungen und Bewertungen der Nachrichten werden die öffentlich zugänglichen Artikel-Inhalte an OpenAI (gpt-Modelle) gesendet. Es werden dabei keine Nutzerdaten übertragen – nur die News-Texte.
